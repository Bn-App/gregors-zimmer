# Gregors Zimmer

Lern-App zu Franz Kafka: *Die Verwandlung* (Training 1) – Schülerinnen und Schüler erarbeiten die Aufgaben Schritt für Schritt, markieren den Text, vergleichen mit Lösungsvorschlägen, speichern Zwischenstände und erstellen ein PDF ihrer Ergebnisse.

Statische Seite (`index.html`), keine Build-Schritte. Auf Vercel als „Other“-Projekt ohne Build-Befehl importieren.
